# 0020 — Installable PWA + offline notice

## Context

Roamint is used primarily from a phone (doc 0014 hotspot LAN, doc 0018 Tailscale
HTTPS + live camera). It currently runs as a plain browser tab. This step makes it
**installable to the home screen** so it launches full-screen like an app, and gives
a clear **"no internet connectivity"** notice when the connection drops instead of
the default Blazor reconnection spinner.

This is deliberately the *small* PWA: installability + a graceful offline notice.
It is **not** offline-capable expense capture. Roamint is Blazor **Server** — the UI
is a live SignalR circuit, so the app fundamentally cannot function without the
server reachable. The service worker exists only to satisfy install criteria and to
serve a friendly offline fallback for navigations; it does **not** try to cache or
replay app interactions. (Real offline capture would require a WASM/hybrid render
mode and a client store + sync — a separate, larger decision, intentionally deferred.)

## Decisions

- **PWA over native.** A native app would force a public JSON API on a single-tenant
  Blazor Server monolith and a second codebase/deployment for one user — wrong tool
  for the complexity. The phone already has live camera over HTTPS; native buys
  almost nothing.
- **Icons generated as real PNGs**, not SVG-only. iOS `apple-touch-icon` needs PNG,
  and PNG 192/512 + maskable is the safest cross-browser install path. Generated by
  a committed, dependency-free Node script (`scripts/gen-pwa-icons.mjs`) using the
  built-in `zlib` — no `npm install`, reproducible, regenerable if the palette
  changes. The mark is the Roamint **"coin pin"**: a map pin whose head is a reeded
  coin (`roam` + `mint`), drawn per-pixel with 4×4 supersampling — teal→mint pin
  gradient over an indigo rounded-square badge, pale-mint coin face with a milled
  edge and a `$` monogram. Maskable variant is full-bleed with the mark held inside
  the central safe zone.
- **Offline notice reuses Blazor's own reconnection UI.** `blazor.web.js` toggles
  CSS classes on an element with `id="components-reconnect-modal"` as the circuit
  drops/recovers (`components-reconnect-show/hide/failed/rejected`). We provide that
  element with custom "No internet connectivity" markup + CSS, so a dropped circuit
  (which on a phone almost always *is* lost connectivity) surfaces as a clear notice
  with a Retry action — no extra JS heartbeat needed. `navigator.onLine` toggles a
  small persistent banner for the can't-even-load-assets case.
- **Service worker is minimal and network-first.** It never caches dynamic app
  responses (a stale Blazor circuit page is worse than none). It precaches only the
  shell assets needed to render `offline.html`, and serves `offline.html` only when a
  *navigation* fails entirely. Has a `fetch` handler (required for installability).
- **`theme-color` = `--bg` (`#0f1115`)** so the status bar / address bar matches the
  dark shell. `display: standalone`, `orientation: portrait`.

## Public surface

Web-host static assets only — no module or DTO changes:

- `wwwroot/manifest.webmanifest`
- `wwwroot/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`,
  `apple-touch-icon-180.png`, `favicon-32.png`
- `wwwroot/service-worker.js`, `wwwroot/offline.html`
- `wwwroot/js/pwa.js` (registers the SW, wires `online`/`offline`)
- `Components/App.razor` — manifest/icon/meta links, reconnect-modal markup, SW reg
- `wwwroot/app.css` — offline-notice styles
- `scripts/gen-pwa-icons.mjs` — icon generator (dev tooling)

## Open questions

- Versioning the SW cache: on each asset change the SW `CACHE` constant must bump to
  evict the old precache. Trivial for now (offline.html rarely changes); revisit if
  the shell grows.
- iOS splash screens (`apple-touch-startup-image`) are per-device-resolution and
  fiddly; skipped for V1 — install + icon + standalone is the 90% win.

## Verification

1. `node scripts/gen-pwa-icons.mjs` regenerates the five PNGs under `wwwroot/icons/`.
2. Run the stack; open over HTTPS (Tailscale) on the phone. Chrome/Edge shows
   "Install app"; iOS Safari → Share → Add to Home Screen uses the monogram icon and
   launches standalone (no browser chrome).
3. Lighthouse PWA audit (desktop Chrome) passes installability checks.
4. Kill connectivity (airplane mode) while the app is open → "No internet
   connectivity" overlay appears with Retry; restoring connectivity recovers the
   circuit and dismisses it.
